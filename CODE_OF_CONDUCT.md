# Code of conduct

This is a small project maintained in spare time. Keep it easy for everyone.

- Be respectful in issues, pull requests and reviews. Disagree with the code, not the person.
- Assume good faith. A bug report that is missing details is an invitation to ask for them, not to dismiss it.
- No harassment, personal attacks, discriminatory remarks or unsolicited contact.
- Stay on topic. Discussion about Studocu's business or other people's use of the extension belongs elsewhere.

Maintainers may edit, hide or lock content that breaks these rules and may block repeat offenders. To report a problem with someone's behaviour in this project, contact the maintainer through GitHub.
